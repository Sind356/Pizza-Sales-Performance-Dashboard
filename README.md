 🍕 Pizza Sales Performance Analysis | SQL Server & Power BI

 Project Overview

The Pizza Sales Performance Analysis project focuses on analyzing pizza sales data to understand business performance, customer ordering patterns, product popularity, and revenue trends.

SQL is used to query and analyze the sales data, while Power BI is used to create an interactive dashboard that presents key performance indicators (KPIs) and visual insights.

The dashboard helps identify top-performing and underperforming pizzas, track monthly revenue, and analyze sales across pizza categories and sizes.

 Project Objectives

- Analyze overall sales performance using key business metrics.
- Track monthly revenue trends and daily order patterns.
- Identify the best-selling and lowest-performing pizzas.
- Understand revenue distribution by pizza category and size.
- Analyze pizza quantities sold across different sizes and categories.
- Build an interactive Power BI dashboard to support data-driven decisions.

 Tools & Technologies

- SQL Server / SQL: Data querying and sales analysis
- Microsoft Power BI: Interactive dashboard development and visualization
- DAX / Power BI measures:KPI calculations, where applicable
- Data Visualization:Line charts, donut charts, area charts, bar charts, and treemaps

Dashboard Features

1. Monthly Revenue Trend
- Tracks revenue performance across all 12 months.
- Highlights monthly fluctuations and revenue peaks.
- Helps identify stronger and weaker sales periods.

 2. Orders by Day of Week
- Analyzes order volumes from Sunday to Saturday.
- Helps identify days with higher and lower order activity.
- Supports planning for staffing and operational demand.

 3. Sales Distribution by Pizza Category
- Compares sales revenue across Classic, Supreme, Veggie, and Chicken pizzas.
- Shows the percentage contribution of each category to total revenue.

 4. Sales Distribution by Pizza Size
- Analyzes revenue contribution from Large, Medium, Small, X-Large, and XX-Large pizzas.
- Helps understand customer preferences by pizza size.

 5. Total Pizzas Sold by Size and Category
- Compares pizza quantities sold across different sizes and categories.
- Helps identify product combinations contributing to sales volume.

 6. Revenue by Pizza Name
- Uses a treemap to compare revenue generated by individual pizza varieties.
- Helps identify high-revenue and low-revenue products.

7. Top and Bottom Pizza Analysis
Identifies pizzas performing best and worst across three measures:

- Revenue generated
- Number of orders
- Quantity sold

 8. Interactive Filters
The dashboard includes slicers for:
- Month
- Pizza category
- Pizza size

These filters allow users to explore sales performance for selected periods and product segments.

 Dataset Description

The project uses a `PIZZA_SALES` table containing sales transaction details.

| Column | Description |

| `pizza _id` | Unique pizza sales record identifier |
| `order_ id` | Order identifier |
| `pizza_name_id` | Pizza product identifier |
| `quantity` | Number of pizzas sold |
| `order_ date` | Date of the order |
| `order _time` | Time of the order |
| `unit_price` | Price per pizza |
| `total_ price` | Total price for the sales record |
| `pizza _size` | Size of the pizza |
| `pizza_ category` | Pizza category |
| `pizza_ ingredients` | Ingredients used in the pizza |
| `pizza_ name` | Name of the pizza variety |
